# Execution Plans

Use durable plans for work that is cross-cutting, risky, architecture-changing, migration/release-sensitive, long-running, or difficult to resume from chat context alone.

Each plan must contain:
- objective and non-goals;
- known facts/assumptions;
- affected surfaces;
- risk/authorization boundaries;
- ordered milestones with evidence;
- progress log;
- decision log;
- validation plan and baseline;
- blockers/failure exits;
- completion criteria.

Templates: [exec-plans/TEMPLATE.md](exec-plans/TEMPLATE.md).
