# Feedback and entropy loop

An observation is `OBSERVED` when sourced and evidenced, `REVIEWED` when classified by a named reviewer, `EVALUATED` when a target regression evaluation exists, and `PROMOTED` only when a separate authorized change records the resulting invariant. Inspection never advances these states.

Entropy inspection reports bounded repository-local findings—broken relative Markdown links, active plans with no matching tracked ledger/change evidence, and missing derived map output. Findings are inputs to normal KEEL changes, not automatic repairs.
