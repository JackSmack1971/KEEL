# Topology and compute routing

## Contract

Routing consumes a validated mission work item and returns only `complexity`, an effort capability (`fast`, `balanced`, `deep`, or `max`), role labels, and verification breadth. It never maps to model names or launches agents.

## Heuristic boundary

Declared `trivial` risk is trivial. High risk with three or more dependencies is critical; high risk or two or more dependencies is complex; the remaining work is standard. This is a transparent recommendation, not an authorization or automatic workflow transition.
