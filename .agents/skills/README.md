# Repository Skills

Keep only coherent recurring workflows that add project-specific policy, knowledge, mechanisms, or verification. Avoid generic persona skills and one-tool wrappers. Every skill needs a routing boundary and should be evaluated against a no-skill baseline before claiming empirical value.

Repository skills:

- `engineering-protocols` — routes recurring debugging, architecture, dependency, migration, security, performance, frontend-runtime, test-remediation, incident, and release concerns.
